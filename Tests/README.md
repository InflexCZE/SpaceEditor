# 本地化检查

在 Windows 上安装 .NET 9 SDK，在项目根目录运行：

```powershell
dotnet run --project Tests/LocalizationChecks.csproj -c Release
```

此检查直接使用 WPF 属性生成和绑定接口，不显示窗口，也不加载游戏或读写用户设置。

覆盖英文默认显示、中文动态名称、内置和自定义预设、双向绑定对象保留、输入 ID 与方块尺寸原值、语言切换不改变区域设置、独立语言包替换、缺少文案时英文回退，以及无效或缺失文件的内置翻译回退。

检查会临时替换测试输出目录内的语言包，结束时恢复原文件。真实游戏操作和可见界面布局仍需手动验收。
